# Product Definition: Kron0

## Vision
Kron0 is a modern, neo-glassmorphism productivity companion designed specifically for students. It seamlessly unifies a focus timer (Pomodoro), a weekly schedule planner, task management, and productivity insights into a high-performance, aesthetically stunning web interface and Progressive Web App (PWA).

## Target Audience
Students, academic researchers, and self-directed learners who require structured time management, schedule tracking, and focus telemetry delivered through a friction-free visual experience.

## Key Features & Capabilities
- **Focus Timer**: Configurable Pomodoro timer with Focus, Short Break, Long Break, and Custom timer modes, tracking telemetry into Firestore.
- **Smart Weekly Schedule**: Horizontal day/week schedule visualizer for managing classes and lectures with start/end time slots.
- **Productivity Analytics**: Visual stats widget tracking total focus duration vs. scheduled class hours to maintain personal balance.
- **Task Management (To-Do)**: Integrated todo task manager with status filters and state management.
- **Neo-Glassmorphism UI**: Dark/neon visual design built with Tailwind CSS, Framer Motion animations, particle effects, and interactive micro-interactions.
- **Real-Time Cloud Sync**: Google Firebase Authentication with Firestore real-time collection listeners scoped per user (`todos`, `entries`, `focus_history`).
- **PWA Capabilities**: Installable Progressive Web App built with Vite PWA plugin.
